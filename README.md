# Unity Blackjack

A 3D blackjack game built in Unity for **UNT CSCE 1010**.

## Team
- Ethan Trombley
- Dabin Choi
- Kallen Schulz

## Built With
- Unity 6 (6000.6.4f1), Universal 3D

## Opening the Project
1. Clone this repository with GitHub Desktop or `git clone`.
2. Install **Unity 6000.6.4f1** through Unity Hub.
3. In Unity Hub, go to **Add → Add project from disk** and select the cloned folder.
4. Open `Assets/Scenes/SampleScene`.
